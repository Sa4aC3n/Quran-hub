# توثيق سلامة المحتوى ومصادر البيانات (Content Integrity & Provenance Documentation)

تحدد هذه الوثيقة المرجعيات المعتمدة، معايير التحقق الصارمة، وهياكل التخزين لمحتوى القرآن الكريم وكتب التفسير المعتمدة في التطبيق، لضمان أصالة النصوص وعدم الاعتماد على أي نصوص مولدة أو غير موثقة.

---

## 1. نص المصحف الشريف (Holy Quran Text)

### أ. الرواية والرسم
- **الرواية**: حفص عن عاصم (Hafs 'an 'Asim).
- **الرسم**: الرسم العثماني المعتمد بمجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة.
- **المصدر الرقمي المعتمد**: مشروع تنزيل القرآني المعتمد عالمياً (Tanzil Project) ومزودات سحابية مطابقة لمعايير المصحف الشريف (`quran-uthmani`).

### ب. معايير ومستويات التحقق الصارمة (Strict Validation Invariants)
يخضع كل ملف سورة يتم جلبه أو حفظه إلى فحص إلزامي لا يقبل الاستثناء عبر `QuranManifest`:
1. **عدد السور**: 114 سورة كاملة مرتبة بدقة من الفاتحة (1) إلى الناس (114).
2. **عدد الآيات لكل سورة**: التحقق التام والمطابق للعدد الكوفي المجمع عليه في مصحف المدينة المنورة (مثل: الفاتحة 7، البقرة 286، آل عمران 200، ... الكوثر 3، الإخلاص 4، الناس 6). يُرفض أي نص سورة يختلف عدد آياته عن العدد الكنسي الموثق.
3. **سلامة الآيات وتسلسلها**:
   - عدم وجود نصوص فارغة أو بيضاء.
   - تسلسل أرقام الآيات داخل السورة بدقة من 1 إلى `numberOfAyahs` دون انقطاع أو تكرار.
4. **فصل البسملة وقواعدها**:
   - سورة الفاتحة (1): البسملة آية مستقلة كاملة برقم (1).
   - السور من (2) إلى (8) ومن (10) إلى (114): تُفصل البسملة الاستفتاحية ولا تُكرر في متن الآية الأولى عند العرض، احتراماً للرسم والعد المعتمد.
   - سورة التوبة (9): لا تبدأ بالبسملة.

### قواعد التحقق الصارمة للردود الشبكية:
- **المصدر C (`api.quran-tafseer.com`)**:
  - فحص حتمي لتطابق `response.tafseer_id == mappedSourceCId`. يُرفض القبول بـ `tafseer_id == 0` أو افتراض التطابق.
  - فحص `ayah_number == requestedAyahNumber`.
  - التحقق من `ayah_url` (المتوافق مع `/quran/{sura}/{ayah}/`) لضمان تطابق السورة المطلوبة والآية، ومنع أي تداخل بين السور.
  - حظر إعادة وسم نصوص مجهولة الهوية بمعرفات الطلب. في حال عدم تطابق الهوية يُرفض الرد فوراً ويُبلغ المستخدم بعدم التوفر.

## 3. المقتطفات المضمنة (Authentic Bundled Offline Seeds)

توفيراً لتجربة قراءة وتفسير أولية آمنة دون اتصال، يتضمن التطبيق حصراً نصوصاً نموذجية كاملة ومحققة لسورتي **الفاتحة (1)** و**الإخلاص (112)**:
1. **نص السور**: مطابق لمصحف المدينة النبوية (مجمع الملك فهد).
2. **التفاسير المضمنة**:
   - **التفسير الميسر**: النص الكامل المعتمد لسورتي الفاتحة والإخلاص الصادر عن مجمع الملك فهد لطباعة المصحف الشريف بالمدينة المنورة (طبعة 1430هـ).
   - **تفسير الجلالين**: النص الكامل لسورتي الفاتحة والإخلاص بتحقيق د. فخر الدين قباوة (دار ابن كثير، طبعة 1419هـ).
   - **تفسير السعدي**: النص الكامل لسورتي الفاتحة والإخلاص من كتاب "تيسير الكريم الرحمن في تفسير كلام المنان" للشيخ عبد الرحمن السعدي (طبعة مؤسسة الرسالة، 1423هـ).
   - **تفسير ابن كثير**: النص الكامل لسورتي الفاتحة والإخلاص من "تفسير القرآن العظيم" لابن كثير (طبعة دار طيبة، تحقيق سامي السلامة، 1420هـ).
3. **الاشتراطات**:
   - جميع المقتطفات آيات وسور كاملة لا عينات جزئية أو توليدية.
   - إرفاق اسم الطبعة والجهة المرجعية كمرجع قابل للتحقق في حقل `sourceProvider` عند القراءة والحفظ.

## 4. مواصفات غلاف التخزين الدائم (Storage Envelopes)

### أ. غلاف السور القرآنية (`SurahStorageEnvelope`)
```json
{
  "schemaVersion": 2,
  "surahNumber": 1,
  "sourceProvider": "api.alquran.cloud/quran-uthmani",
  "editionIdentifier": "quran-uthmani",
  "datasetVersion": "UNKNOWN",
  "timestamp": 1726830000000,
  "surahText": { ... }
}
```

### ب. غلاف التفسير (`TafseerStorageEnvelope`)
```json
{
  "schemaVersion": 2,
  "tafseerId": 1,
  "surahNumber": 1,
  "ayahNumber": 1,
  "sourceProvider": "quranenc.com/arabic_moyassar",
  "datasetVersion": "1430H",
  "timestamp": 1726830000000,
  "response": { ... }
}
```

### ج. دورة الكتابة الذرية (Atomic Writing Cycle)
- استخدام `android.util.AtomicFile` مع قفل ملفي مشترك عبر `StorageLockManager`.
- التسلسل الإلزامي: `startWrite()` -> كتابة البيانات -> `flush()` -> `fd.sync()` -> `finishWrite()`. وفي حال حدوث أي استثناء: استدعاء `failWrite()`.
- ربط النجاح حصراً بنجاح إعادة القراءة والتحقق من صحة الملف بعد اكتمال الكتابة.
